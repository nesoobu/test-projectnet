# Лера 2.0

Telegram Mini App для геймеров: поиск тиммейтов по любым играм, отряды, турниры, вики, лента и мини-игры.

## Что нового в 7.0 — вики

- Вики-хаб по **всем 9 играм** (переключатель игр сверху): об игре, роли с описанием и числом игроков в Лере,
  лестница рангов, режимы, база для новичков, словарь терминов (`app/wiki_content.py`).
- **Герои / агенты / бойцы / персонажи / карты** — сетка с поиском, фильтрами по классу и роли, сортировкой.
- **Тир-лист от игроков**: каждый ставит S–D, есть «быстрая оценка» подряд.
- **Страница героя**: тир и распределение голосов, «мой мейн», кто мейнит в Лере (→ анкета), советы игроков с лайками,
  гайды по герою, похожие.
- **Гайды**: категории (новичкам, по герою, тактика, мета), привязка к герою, лайки «полезно».

## Что нового в 6.0

- **Лера больше не про одну HoK:** Лерадл для HoK, MLBB, Dota 2, Valorant, Brawl Stars и Genshin (своя загадка и стрик),
  вики с героями/агентами/бойцами/персонажами и картами CS2/PUBG M, опрос дня через день — про твою игру.
- **Турниры 2.0:** Bo1/Bo3/Bo5, взнос и призовой фонд (приз + взносы, делёж 100 / 70-30 / 60-40 на 1–2 место),
  чек-ин за 30 минут (не отметился — снят, взнос вернулся), автостарт по времени (не набралось — отмена с возвратом),
  напоминание за 30 минут. Капитаны сами отправляют результат: совпало — матч закрыт, нет — спор уходит админу
  (Админка → Контент → споры), молчание соперника 30 минут = согласие. Код лобби рассылается обеим командам,
  чат турнира для участников и орга, счёт в сетке, 🏆 трофеи в анкете.

## Что нового в 5.0

- **Реалтайм (WebSocket `/ws`):** мгновенные сообщения в личке, отрядах и кланах, «печатает…», живые счётчики,
  настоящий онлайн-статус. Опрос сервера остался страховкой.
- **Центр уведомлений** (колокольчик на главной) + всплывашки в приложении. Пока игрок в Лере, бот ему не пишет.
- **Друзья:** заявки, список с онлайном и «ищет пати», личные сообщения, **подарки** (несо и предметы).
- **Быстрый поиск пати:** очередь матчмейкинга — Лера сама собирает отряд близкого ранга с разными ролями
  (фильтр смягчается со временем), создаёт чат и зовёт всех. Таймаут 20 минут.
- **Инфраструктура:** ежедневный бэкап базы в `data/backups/` (7 последних), фото ужимаются до 1600px.

## Что нового во v4

- **Клипы** (Лента → Клипы): видео до 40 МБ, вертикальный плеер со свайпом, лайки, просмотры. По понедельникам
  «клип недели» получает 300 несо и пост в ленте. В Caddy нужен `max_size 50MB`.
- **Прогнозы** на матчи турниров: ставка несо на победителя, тотализатор — проигравшие ставки делятся между угадавшими.
- **ИИ-Лера** (Главная → «Спроси Леру»): чат-помощник по играм и приложению на Claude. Нужен `ANTHROPIC_API_KEY` в `.env`;
  лимит 15 вопросов в день (60 с Premium), модель меняется через `LERA_AI_MODEL`.

## Что нового во v3

- **Кланы:** тег и эмблема, уровни (растут от опыта бойцов), открытые или по заявке, роли лидер/офицер/боец,
  общий чат, топ недели. Создание стоит 500 несо. Вкладка «Тиммейты → кланы».
- **Боевой пропуск:** сезон = месяц, 30 уровней, бесплатная и премиум-линейка, сезонная косметика.
  Опыт пропуска — любой xp в Лере. Премиум-линейка — 149 ⭐ или бесплатно с Lera Premium.
- **Промокоды** (несо, тикеты, premium, предметы) — ввод в профиле.
- **Админка с вкладками:** обзор с графиками DAU/регистраций и экономикой; игроки (поиск, карточка, выдача/списание,
  бан, чистка фото/ника/постов); жалобы; контент; рассылка в бота с фильтрами; промокоды; журнал действий админов.

## Что нового во v2

- **9 игр** (HoK, MLBB, PUBG M, Standoff 2, CS2, Dota 2, Valorant, Brawl Stars, Genshin) — у каждой свои ранги, роли, режимы.
  Игра добавляется одной записью в `app/content.py → GAMES`. Переключатель игры в шапке, у игрока — отдельный профиль под каждую игру.
- **Новая навигация:** Главная · Тиммейты (дуэт + отряды) · Лента · Чаты · Я.
- **«Готов играть»** — клич в бота всем игрокам этой игры; кнопка «го» сразу открывает чат.
- **Репутация:** отзывы 👍/👎 с тегами после мэтча или отряда.
- **Турниры:** соло и командные, регистрация, автоматическая сетка, победители, призы в несо, анонсы в ленте.
- **Вики:** герои (HoK) + гайды игроков с модерацией (+100 несо за опубликованный).
- **Лента с автопостингом:** RSS/Atom-источники (для Telegram-каналов — через RSS-мост), посты Леры по расписанию,
  авто-события (отряд собран, легендарка, итоги турнира, итоги недели по понедельникам). Фильтр «эта игра / все».
- **Каждый день:** Лерадл (угадай героя дня, стрик, шаринг), опрос дня, квесты, ×2 награды по выходным.
- **Ачивки** с наградами.
- **Админка:** турниры, опрос дня, пост от Леры, RSS, модерация гайдов, статистика.

Старая база мигрирует сама при запуске (новые таблицы и колонки, анкеты HoK переносятся в профиль игры).
Написана заново. Фронт без сборщика: никакого Vite, Replit, `fix_build.py` и ошибок `Cannot access 'X' before initialization`.

```
app/        FastAPI-бэкенд + бот (aiogram) — одна база SQLite
web/        фронт: index.html + styles.css + ES-модули (правишь файл → обновил страницу)
scripts/    seed_demo.py (демо-данные), import_old.py (перенос игроков из старой базы)
```

## Что внутри

**Из старой Леры (и починено)**
- Дуэт: свайпы, лайки, мэтчи, уведомления в боте. Карточки на весь экран.
- Фильтры за шестерёнкой: онлайн/все, пол, возраст, ранг, роль. Блоки «Лера советует» и прочие убраны.
- Вкладка «Лайки». Ответный лайк сразу даёт мэтч.
- Чат мэтча через API. Раньше он жил в localStorage и был виден только отправителю.
- Отряды (лобби) с чатом. Аватарки в чате на месте, `id` — нормальный autoincrement.
- Профиль, фото (до 4), анкета дуэта (раньше вместо неё была заглушка).
- Инвентарь: рамки теперь реально видны везде (в анкете, чатах, ленте, топе).
- Ежедневка, кошелёк, магазин, гача, топ, лента, вики, premium, помощь.

**Новое**
- **Вайб** — совместимость 12–99 с объяснением: роли закрывают друг друга, близкий ранг, общее время игры, микро, город, общие мейны.
- **Суперлайк** (свайп вверх): такой игрок первым стоит в ленте у того, кого лайкнули. **Отмена свайпа** в Premium.
- Штампы «ГО / МИМО / СУПЕР» при свайпе, хаптика Telegram, экран мэтча.
- **Ледоколы** в пустом чате, статусы «доставлено / прочитано», счётчики непрочитанного.
- **Онлайн-статус** (heartbeat), фильтр «только онлайн».
- **Стрик** ежедневки 7 дней: награда растёт, на 7-й день тикет в гачу.
- **Ежедневные квесты** с наградами.
- **Гача** с гарантом легендарки (pity 50), десяткой минимум с редким, возвратом за дубли и анимацией вскрытия.
- Косметика: рамки (неон, глитч, угли, золото…), цвет ника (вплоть до переливающегося), титулы, баннеры профиля.
- **Свой цвет приложения** — акцент меняется под игрока.
- **Рефералка**: +100 другу, +150 тебе. Приглашение в отряд ссылкой.
- **Оплата звёздами Telegram (Stars)**: Premium на 30 дней и пакет несо.
- **Жалобы и блок**: заблокированный пропадает отовсюду, жалоба уходит админу.
- Вики героев с кнопкой «мейн» и счётчиком «мейнят N».
- Мини-админка со статистикой.
- Проверка подписи `initData` на сервере: подделать чужой `tg_id` нельзя.

## Запуск локально

```bash
cd lera
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # DEV_USER_ID=1001 — вход без Telegram
python -m scripts.seed_demo     # 12 демо-игроков, пост, отряд
uvicorn app.main:app --port 23054
# открыть http://localhost:23054/?dev=1001   (?dev=2000 — войти другим игроком)
```

## Деплой на сервер (sportingtan)

```bash
# 1. код
cd /opt && git clone <repo> lera2 && cd lera2/lera
python3 -m venv venv && . venv/bin/activate && pip install -r requirements.txt
cp .env.example .env && nano .env      # BOT_TOKEN, WEBAPP_URL, ADMIN_IDS; DEV_USER_ID оставить пустым!

# 2. (по желанию) перенести игроков из старой базы
python -m scripts.import_old /root/ler/data/lera_bot.db
```

`/etc/systemd/system/lera-web.service`
```ini
[Unit]
Description=Lera mini app
After=network.target
[Service]
WorkingDirectory=/opt/lera2/lera
ExecStart=/opt/lera2/lera/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 23054
Restart=always
[Install]
WantedBy=multi-user.target
```

`/etc/systemd/system/lera-bot.service` — то же самое, но `ExecStart=/opt/lera2/lera/venv/bin/python -m app.bot`.

```bash
systemctl stop lera-miniapp            # старый мини-апп (порт тот же)
systemctl daemon-reload
systemctl enable --now lera-web lera-bot
```

nginx не трогаем: `app.lerarubot.ru → 127.0.0.1:23054` уже настроен. Нужно только `client_max_body_size 8m;` для загрузки фото.

> ⚠️ Бот должен работать **одним** процессом. Если старый бот из `/root/ler/` ещё запущен с тем же токеном, polling будет конфликтовать.
> Остановите его или оставьте старого бота, а `lera-bot` не запускайте. Тогда не будет оплаты Stars и рефералок через `/start`, всё остальное работает.

**Обновление:** `git pull && systemctl restart lera-web lera-bot`. Сборки нет.
