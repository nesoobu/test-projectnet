# ⭐️ Stars Shop Bot

Telegram-бот для продажи Telegram Stars (себе и в подарок). Почти весь интерфейс настраивается из админ-панели прямо в боте, без правки кода.

Стек: Python 3.11+, aiogram 3.31 (Bot API 9.x), SQLite (aiosqlite).

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # укажите BOT_TOKEN и ADMIN_IDS
python -m bot
```

Админ-панель открывается командой `/admin` (доступна только ID из `ADMIN_IDS`).

## Что умеет

**Покупателю**
- пакеты звёзд и своё количество (мин./макс. задаются в настройках);
- покупка себе (одной кнопкой) или подарок по @username;
- оплата: с баланса, через CryptoBot (USDT/TON и др., проверяется автоматически) или вручную картой с отправкой чека;
- пополнение баланса;
- промокоды (скидка в %, лимит активаций, один раз на пользователя);
- реферальная программа: % с каждой покупки друга начисляется на баланс;
- профиль, история заказов, FAQ, поддержка.

**Админу (`/admin`)**
- 📝 **Экраны и тексты.** Каждое сообщение бота — это экран: текст, медиа и кнопки. У любого экрана можно:
  - поменять текст с форматированием (жирный, ссылки, спойлеры, премиум-эмодзи сохраняются; можно писать HTML вручную, перед сохранением разметка проверяется);
  - прикрепить фото, видео, GIF или файл (подпись к медиа сразу становится текстом);
  - посмотреть превью;
  - создать новый экран (акция, правила, отзывы...) и повесить его на кнопку.
- 🔘 **Кнопки.** Добавление, удаление, вкл/выкл, расстановка по рядам. Для каждой кнопки настраиваются:
  - текст и эмодзи;
  - **премиум-эмодзи** (`icon_custom_emoji_id`): достаточно прислать его сообщением;
  - **цвет**: синий, зелёный или красный (`style`, Bot API 9.4+);
  - действие: открыть экран, запустить функцию бота (покупка, подарок, профиль, рефералы, промокод, пополнение...), ссылка, Mini App, «скопировать текст», всплывающее окно.
- 🔘 **Системные кнопки.** Кнопки, которые бот строит сам (пакеты, способы оплаты, «Себе», «Проверить оплату»...), тоже редактируются: текст, эмодзи, премиум-эмодзи, цвет.
- 💎 **Пакеты.** Количество, фиксированная цена или цена по курсу, вкл/выкл.
- ⚙️ **Настройки.** Курс, валюта, лимиты, способы оплаты, токен CryptoBot, реквизиты, режим выдачи, обязательная подписка, техработы, чат для логов.
- 📦 **Заказы.** Подтверждение чеков, «звёзды выданы», повтор автовыдачи, отмена с возвратом на баланс, поиск через `/order ID`.
- 🎟 Промокоды, 👤 пользователи (баланс, бан), 📢 рассылка (любое сообщение с кнопками), 📊 статистика (выручка, конверсия, заказы, требующие внимания).

Плейсхолдеры в текстах: `{name} {username} {id} {balance} {currency} {rate} {min_stars} {max_stars} {support} {ref_link} {ref_percent}`. На экранах заказа также доступны `{order_id} {stars} {recipient} {amount} {card} {discount_line}`.

## Выдача звёзд

- `delivery_mode = manual`: после оплаты админ получает уведомление и нажимает «✅ Звёзды выданы» (например, после покупки через Fragment вручную).
- `delivery_mode = api`: бот вызывает `POST delivery_api_url` с JSON `{"username", "quantity", "order_id"}` и заголовком `Authorization: Bearer <delivery_api_key>`. Так подключается любой Fragment-провайдер или ваш скрипт на TON-кошельке; формат запроса меняется в `services._deliver_api`. Если API вернул ошибку, заказ получает статус `failed`, а админ получает кнопки «Повторить» и «Выдано вручную».

Повторная выдача исключена: смена статусов атомарная (`UPDATE ... WHERE status IN (...)`).

## Что обычно не хватает таким ботам и что можно добавить

Это обзор типичных слабых мест конкурентов. ✅ отмечено то, что уже сделано здесь.

**Доверие и прозрачность**
- ✅ Понятный статус заказа и история; ✅ уведомление о выдаче.
- Канал с отзывами и автопостинг выполненных заказов (с маскировкой ника): даёт социальное доказательство.
- Публичный счётчик «продано звёзд / выполнено заказов» на главном экране.
- Гарантия и автоматический возврат на баланс, если заказ не выдан за N минут.

**Оплата**
- ✅ CryptoBot, ✅ баланс, ✅ ручная оплата картой с чеком.
- СБП или эквайринг через платёжные агрегаторы (ЮKassa, CloudPayments, Lava, AAIO и т.п.), чтобы не проверять чеки вручную.
- TON Connect: оплата прямо из Tonkeeper или Wallet, с проверкой транзакции по комментарию.
- Мультивалютность и автообновление курса (TON/USDT → RUB) с наценкой в %.

**Выдача**
- ✅ Автовыдача через API и fallback на ручную выдачу.
- Проверка, что @username существует, **до** оплаты (через Fragment search). Самая частая причина споров — опечатка в нике.
- Telegram Premium-подписки и подарки (gifts) в том же боте: та же аудитория, тот же Fragment.
- Очередь и ретраи с экспоненциальной задержкой, алерт при низком балансе кошелька Fragment.

**Удержание и маркетинг**
- ✅ Рефералка, ✅ промокоды, ✅ рассылки.
- Многоуровневая рефералка и вывод реферальных средств.
- Скидки по объёму (кэшбэк или уровни: чем больше куплено, тем ниже курс).
- Сегментированные рассылки (только покупателям, неактивным 30 дней, бросившим корзину) и отложенная отправка.
- Напоминание о брошенном заказе через 15 минут.
- UTM-метки в `/start` для отслеживания рекламных источников и их конверсии.

**Интерфейс**
- ✅ Всё редактируется из админки: тексты, медиа, эмодзи, премиум-эмодзи, цвет кнопок, новые экраны.
- Мультиязычность (RU/EN/UZ...) с выбором языка: та же таблица экранов с полем `lang`.
- Inline-режим (`@bot 100`) для покупки прямо из любого чата.
- Mini App с калькулятором и красивой витриной.

**Безопасность и надёжность**
- ✅ Антифлуд, ✅ бан, ✅ техработы, ✅ атомарные статусы, ✅ защита от двойного списания.
- Роли админов (оператор видит только заказы, владелец видит всё) и журнал действий админов.
- Ежедневный бэкап БД в приватный канал.
- Webhook вместо polling и PostgreSQL + Redis (FSM) при росте нагрузки.
- Антифрод: лимиты на сумму или число заказов для новых аккаунтов, чёрный список ников-получателей.

## Структура

```
bot/
  __main__.py      запуск, роутеры, фоновые задачи
  config.py        .env
  db.py            схема SQLite, начальное наполнение, хелперы
  defaults.py      экраны, кнопки, настройки по умолчанию
  render.py        отрисовка экранов: текст, медиа, кнопки, плейсхолдеры
  services.py      заказы, CryptoBot, выдача, уведомления
  middleware.py    регистрация, рефералы, бан, техработы, подписка, антифлуд
  handlers/user.py   пользовательские сценарии
  handlers/admin.py  админ-панель
```

> Премиум-эмодзи в тексте и на кнопках отображаются, только если у владельца бота есть Telegram Premium или бот купил дополнительный username на Fragment.
