# ⭐️ Stars Shop Bot

Telegram-бот для продажи Telegram Stars и Telegram Premium, себе или в подарок. Почти весь интерфейс (тексты на нескольких языках, медиа, кнопки, эмодзи, цвета, новые разделы) настраивается в админ-панели прямо в боте.

Стек: Python 3.11+, aiogram 3.31 (Bot API 9.x), SQLite (WAL), по желанию Redis и webhook.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN и ADMIN_IDS
python -m bot
```

Админ-панель открывается командой `/admin`. Для inline-режима включите его в @BotFather (`/setinline`).

## Возможности

### Покупателю
- **Звёзды:** пакеты или своё количество, себе одной кнопкой или в подарок по @username.
- **Telegram Premium** на 3, 6 или 12 месяцев (пакеты задаются в админке).
- **Проверка получателя до оплаты:** бот проверяет, что @username существует и это не канал или группа, и показывает имя получателя в заказе.
- **Оплата:**
  - с баланса;
  - **CryptoBot** (USDT, TON и др.);
  - **ЮKassa** (карты, СБП);
  - **TON** напрямую на ваш кошелёк, через Tonkeeper, с комментарием;
  - вручную картой с отправкой чека.

  Автоматические способы проверяются в фоне, отдельно нажимать «проверить» не нужно.
- **Скидки:** уровни по объёму (например, купил 1000 ⭐️ и получает −2% навсегда) и промокоды. Скидки суммируются, максимум 90%.
- **Рефералка в 2 уровня** с выводом заработанного (заявка уходит админу).
- Пополнение баланса, история заказов, профиль с уровнем.
- **Отзывы** после выполнения заказа: оценки 4–5 публикуются в канал, 1–3 уходят админам.
- **Напоминание о брошенном заказе** с кнопкой «Продолжить».
- **Мультиязычность:** RU и EN из коробки. Язык определяется по Telegram, его можно сменить в профиле. Добавить язык можно настройкой `languages`.
- **Inline-режим:** `@bot 500` в любом чате выдаёт карточку с ценой и кнопками «Купить» и «Подарить».
- **Mini App витрина** (`webapp/index.html`): калькулятор, пакеты и кнопка покупки, цвета подстраиваются под тему Telegram.

### Админу (`/admin`)
- 📝 **Экраны.** Любое сообщение бота можно настроить:
  - текст с форматированием и премиум-эмодзи, отдельно для каждого языка;
  - фото, видео, GIF или файл;
  - превью;
  - новые экраны.

  Перед сохранением HTML проверяется.
- 🔘 **Кнопки.** Добавить, удалить, расставить по рядам, включить или выключить. У каждой кнопки настраиваются текст (для каждого языка), эмодзи, **премиум-эмодзи**, **цвет** и действие: экран, функция бота, ссылка, Mini App, копирование текста или всплывающее окно. В ссылках работают плейсхолдеры (`{bot_username}`, `{webapp_link}`).
- 🔘 **Системные кнопки.** Пакеты, способы оплаты и прочие кнопки, которые бот строит сам, тоже редактируются.
- 💎 **Пакеты** звёзд и Premium.
- ⚙️ **Настройки** по группам: цены (в том числе **автокурс** — себестоимость × курс USD × наценка), оплата, выдача, рефералы, антифрод, каналы, языки, система.
- 📦 **Заказы** (подтверждение чеков, «выдано», повтор API, отмена с возвратом) и 💸 **выводы**.
- 📢 **Рассылки:**
  - сегменты: все, покупатели, без покупок, неактивные 30+ дней, бросившие заказ, по языку;
  - отправка сразу или **по расписанию**.
- 📊 **Статистика:** выручка, конверсия, активные пользователи. 📈 **Источники (UTM):** `t.me/bot?start=метка` показывает пользователей, покупателей и выручку по каждой метке. ⭐️ **Отзывы**.
- 👮 **Роли:** owner (всё) и operator (только заказы и выводы). 📜 **Журнал** действий админов.
- 💾 **Бэкап** по кнопке и ежедневно в указанный чат.

### Надёжность и безопасность
- **Защита от двойной выдачи и двойного списания:** все смены статуса атомарные.
- **Автовыдача через API.** При ошибке бот повторяет попытку через 1, 2, 4… минуты. После N неудач админ получает кнопки «Повторить» и «Выдано вручную».
- **Автовозврат на баланс**, если заказ не выдан за N минут (выключен по умолчанию).
- **Алерт о низком балансе** у провайдера выдачи.
- **Антифрод:**
  - лимит суммы заказа для новых аккаунтов;
  - лимит заказов в сутки;
  - чёрный список получателей;
  - антифлуд;
  - бан;
  - режим техработ;
  - обязательная подписка на канал.
- **Webhook** вместо polling (`WEBHOOK_URL`) и **Redis** для FSM (`REDIS_URL`), см. `.env.example`.
- **Миграции:** база первой версии обновляется автоматически при запуске.

## Выдача товара

- `delivery_mode = manual`: админ получает уведомление и нажимает «✅ Выдано».
- `delivery_mode = api`: бот отправляет `POST delivery_api_url` с заголовком `Authorization: Bearer <delivery_api_key>` и телом:
  ```json
  {"type": "stars", "username": "durov", "quantity": 500, "order_id": 1}
  {"type": "premium", "username": "durov", "months": 3, "order_id": 2}
  ```
  Успех: HTTP 200 и в ответе нет `"ok": false`. Если формат вашего Fragment-провайдера другой, поправьте `services._deliver_api`.
- `delivery_balance_url`: GET, который возвращает `{"balance": число}`, нужен для алерта о низком балансе.

## Подключение оплаты

| Способ | Настройки | Примечание |
|---|---|---|
| CryptoBot | `pay_crypto`, `cryptobot_token` | Токен: @CryptoBot → Crypto Pay → Create App |
| ЮKassa | `pay_yookassa`, `yk_shop_id`, `yk_secret` | Если магазин работает по 54-ФЗ, добавьте `receipt` в `services.yk_invoice` |
| TON | `pay_ton`, `ton_wallet`, `toncenter_key` (по желанию) | Курс берётся с CoinGecko, платёж ищется по комментарию `order-ID` |
| Карта | `pay_manual`, `card_details` | Пользователь присылает чек, админ подтверждает |

## Mini App

1. Разместите `webapp/index.html` на любом HTTPS-хостинге (GitHub Pages, Vercel, Netlify).
2. Укажите URL в настройке `webapp_url`.
3. Включите в «Главном меню» кнопку «🛍 Витрина»: её действие уже стоит `{webapp_link}`, бот сам подставит цены и пакеты.

## Плейсхолдеры

Общие: `{name} {username} {id} {balance} {currency} {rate} {min_stars} {max_stars} {support} {ref_link} {ref_percent} {ref_percent2} {sold_stars} {done_orders} {users_count} {bot_username} {webapp_link}`.

На экранах заказа: `{order_id} {product} {stars} {months} {recipient} {recipient_display} {recipient_masked} {amount} {card} {discount_line} {ton_amount} {ton_wallet} {ton_comment}`.

Профиль и рефералы: `{total_stars} {orders_count} {level_discount} {next_level} {ref_count} {ref_count2} {ref_earned} {withdraw_available}`.

## Структура

```
bot/
  __main__.py        запуск: polling или webhook, Redis, роутеры, фоновые задачи
  config.py          .env
  db.py              схема, миграции, начальное наполнение, i18n
  defaults.py        экраны (RU и EN), кнопки, настройки по умолчанию
  render.py          отрисовка экранов: язык, медиа, кнопки, плейсхолдеры
  services.py        цены, заказы, оплаты, выдача, рефералы, рассылки, бэкап, фон
  middleware.py      регистрация, рефералы, UTM, язык, бан, техработы, подписка, антифлуд
  handlers/user.py   сценарии покупателя
  handlers/admin.py  админ-панель
  handlers/inline.py inline-режим
webapp/index.html    Mini App витрина
```

## Ограничения

- Премиум-эмодзи в тексте и на кнопках видны, только если у владельца бота есть Telegram Premium или бот купил дополнительный username на Fragment.
- Проверка получателя работает через публичную страницу `t.me/username`. Если страница недоступна, заказ не блокируется.
- Хранилище — SQLite: его хватает на десятки тысяч пользователей. Для PostgreSQL нужно переписать `db.py`, код снаружи от него почти не зависит.
- Telegram-подарки (gifts) не реализованы: Bot API отправляет их только по user_id и за звёзды самого бота.
